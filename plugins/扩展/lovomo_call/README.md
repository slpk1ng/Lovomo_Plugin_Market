# 语音通话（lovomo_call）

在浏览器里和角色打电话：按住说话 → 语音识别 → 角色回复 → 语音合成播回。
后端接口在 modules/webui_server.py：GET /api/call/status、POST /api/call/turn。

## 用法
1. 页面顶部选角色、留痕档、识别语种，勾上「记住这次通话」。
2. 按住大圆按钮说话，松手结束；也可以点一下开始、再点一下结束。
3. 说完会显示识别出来的文字和角色回复，并自动播放第一句台词的语音。
4. 「挂断」只清空屏幕上这一通，不删角色记忆，记忆由留痕档决定。

## 隐私
- 语音识别默认走本机（asr_engine 为 local），音频不出这台机器；只有你在设置里把识别引擎改成云端才会把音频传出去。
- 留痕默认「只留文字」：文字写进角色记忆，原始录音与合成出来的 wav 用完即删，磁盘上不留音频文件。
- 留痕选「完全不留痕」并且不勾「记住这次通话」，这一轮就什么都不写进角色记忆。
- 留痕选「文字+原始录音」才会把你的原始录音另存到 data/calls/ 下（文件名带时间戳），方便自己排查；想清掉直接删那个目录即可。
- 合成语音只按第一句台词生成一份临时 wav 返回给页面播放，不落到记忆目录。

## 手机上用麦克风
浏览器只在 https 或 localhost 下才把麦克风交给网页。要在手机上用，请在设置里打开 WebUI 的
HTTPS（程序会自签一张证书），再用 https://<你的局域网IP>:<端口> 打开手机浏览器，证书告警
选择继续访问即可。
