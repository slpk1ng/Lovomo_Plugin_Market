# 官方市场的第三方来源清单。
#
# 每行写一个「用户名/仓库名」（也接受直接粘 GitHub 地址），# 开头是注释。
# 清单里的仓库两种上架方式都认：先读它的 plugins/index.json 索引，索引里
# 没有条目时再按分支扫（名字以插件分支前缀开头的分支即为一个插件，
# 分支根目录放 plugin.yaml）。
#
# 想让自己的插件进官方市场：
#   1. 把「官方市场仓库」配置改填成自己的仓库，用程序里的「发布到市场」把插件发上去；
#   2. 往本文件加一行自己的仓库地址，给本仓库提一个 Pull Request；
#   3. 合并后官方市场就会扫到它。
#
# 前提：官方市场仓库的「来源清单路径」要填成这个文件（配置文件 → 插件系统 → 来源清单路径）。
# 注意 GitHub 匿名读取有次数限制，清单别堆太多仓库。
#
# 示例（去掉行首的 # 即可生效）：
# your-name/your-lovomo-plugins
